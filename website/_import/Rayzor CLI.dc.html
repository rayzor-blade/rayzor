Project manifest

A rayzor.toml at the project root. A workspace lists members instead, and an existing HXML build can be delegated to rather than ported.

rayzor.toml
[project] name = "my-app" version = "0.1.0" entry = "src/Main.hx" [build] class-paths = ["src"] opt-level = 2 preset = "application" output = "build/my-app" [cache] enabled = true
workspace
[workspace] members = ["game", "engine", "tools/level-editor"] [workspace.cache] dir = ".rayzor/cache"
delegate to HXML
[project] name = "legacy-app" hxml = "build.hxml"

A project depending on native plugins must declare both the class paths and the native libraries; a consumer with only one of the two fails to resolve at run time.
